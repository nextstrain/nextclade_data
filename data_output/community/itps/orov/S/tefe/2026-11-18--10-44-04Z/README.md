# Nextclade Dataset for "OROV" S segment based on Reference "ILMD_TF29"

## Dataset Attributes

| Attribute            | Value                                       |
| -------------------- | ------------------------------------------- |
| Name                 | orov/S/tefe                                 |
| RefName              | Oropouche virus isolate ILMD_TF29 segment S |
| RefAccession         | PP154170.1                                  |

## Scope of This Dataset

The dataset aims to enable the quality control of segment S of Oropouche virus using a genome from [Tefe outbreak](https://pubmed.ncbi.nlm.nih.gov/29623245/) (ILMD_TF29) as reference.

This dataset was originally developed by Filipe Dezordi on behalf of Instituto Todos pela Saúde (ITpS)
with [InstitutoTodosPelaSaude/nextclade-datasets-workflows](https://github.com/InstitutoTodosPelaSaude/nextclade-datasets-workflows/tree/main/orov).
It is now maintained directly in [nextstrain/nextclade_data](https://github.com/nextstrain/nextclade_data/tree/master/data/community/itps/orov/S/tefe), which holds its current files.

For bugs, please open an [issue](https://github.com/nextstrain/nextclade_data/issues) in nextstrain/nextclade_data.

Read more about Nextclade datasets in the Nextclade documentation: [Nextclade Datasets](https://docs.nextstrain.org/projects/nextclade/en/stable/user/datasets.html).
