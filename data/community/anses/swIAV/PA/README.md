## Scope of this dataset
This dataset uses A/California/07/2009(H1N1) as a reference sequence to assign clades to swIAV strains based on an improved OctoFlu nomenclature for the PA segment.

## Features
This dataset supports

 * Assignment to clades based on OctoFlu work with improvements and new clades based on OFFLU data
 * Sequence QC
 * Phylogenetic placement
