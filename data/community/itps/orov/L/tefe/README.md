# Nextclade Dataset for "OROV" L segment based on Reference "ILMD_TF29"

## Dataset Attributes

| Attribute            | Value                                       |
| -------------------- | ------------------------------------------- |
| Name                 | orov/L/tefe                                 |
| RefName              | Oropouche virus isolate ILMD_TF29 segment L |
| RefAccession         | PP154172.1                                  |

## Genome Annotation

The L segment encodes one RNA-dependent RNA polymerase, annotated as the CDS `RdRp`. Unlike the M
polyprotein, the L protein is not known to be processed into separate mature proteins.

## Scope of This Dataset

The dataset aims to enable the quality control of segment L ofOropouche virus using a genome from [Tefe outbreak](https://pubmed.ncbi.nlm.nih.gov/29623245/) (ILMD_TF29) as reference.

This dataset was originally developed by Filipe Dezordi on behalf of Instituto Todos pela Saúde (ITpS)
with [InstitutoTodosPelaSaude/nextclade-datasets-workflows](https://github.com/InstitutoTodosPelaSaude/nextclade-datasets-workflows/tree/main/orov).
It is now maintained directly in [nextstrain/nextclade_data](https://github.com/nextstrain/nextclade_data/tree/master/data/community/itps/orov/L/tefe), which holds its current files.

For bugs, please open an [issue](https://github.com/nextstrain/nextclade_data/issues) in nextstrain/nextclade_data.

Read more about Nextclade datasets in the Nextclade documentation: [Nextclade Datasets](https://docs.nextstrain.org/projects/nextclade/en/stable/user/datasets.html).
